4

Where AI sits, where the chain sits

AI decides

  • The buyer agent is a Claude model with five tools: list proofs, read its own spending policy, buy over x402, skip with a reason, write the report.
  • Input is a sentence: "buy the proofs for this lot, budget 30 USDT, reject any farm with deforestation."
  • It handles the messy part: hundreds of farms, edge cases, conflicting instructions, and explains every decision.

Why an agent and not a script: the rules change per buyer, per country, per lot. A script breaks; an agent reads the instruction.

Chain enforces

  • Registry: the attestation hash is anchored by the farmer's key. Any buyer, bank or auditor verifies it without trusting us.
  • Stablecoin: machines don't have bank accounts. USDT is how one program pays another, instantly, to any farmer anywhere.
  • AgentWallet: daily limit, per-payment limit, allow-listed payees. The AI holds a key that cannot exceed the policy, even if tricked.

Why a chain and not a database: the trader's agent and the farmer's agent don't trust each other, and neither should have to trust a middleman.

The check is SQL, and we run it locally. The trade is not: two companies that don't trust each other, two programs paying each other, and an AI holding money it cannot misuse.

Under the hood

farmer · privateField ∩ PRODES

Pure geometry against INPE's public polygons. No ML, no cloud, runs on a laptop.

farmer · privateEIP-712 attestation

Area, ha deforested after 2020, verdict, source, timestamp. Signed by the farmer.

HSK ChainAnchor

attest(hash, fieldId). Only commitments on-chain. Revocable by the farmer.

buyer · LLM402 → AgentWallet.pay

x402 v1 shape. On-chain USDT transfer, replay-protected, policy-enforced.

buyer · LLMVerify & report

Signature → same farmer anchored it → not revoked. Markdown dossier with every tx.

  • Honest limits today: settlement by tx hash, not EIP-3009; attestations are self-signed, so this proves authenticity and integrity, not a field inspection.
  • Next: EIP-3009 gasless settlement · ZK proof of empty intersection · Sentinel-2 change detection on the farmer's machine · IBAMA embargoes · cattle passports.
7

Built to scale: any farmer, any buyer, one registry.

  • Each farmer runs their own agent with their own key. A lot spans many farmers; the buyer's agent works the whole lot from one instruction.
  • The registry is the global index: every proof, every farmer, verifiable by any bank, importer or auditor without a middleman.
  • FieldAttestationRegistry, AgentWallet and the x402 seller are generic: any private dataset can become a paid, verifiable proof.
